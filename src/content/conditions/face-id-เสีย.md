## Face ID เสีย คืออะไร และทำไมถึงกระทบการขาย

**Face ID** คือระบบสแกนใบหน้าของ Apple ที่ใช้กล้อง **TrueDepth** บริเวณรอยบัวด้านบนของ iPhone
เมื่อระบบนี้เสีย คุณอาจพบข้อความ “Face ID Is Not Available” สแกนไม่ผ่าน หรือต้องใช้รหัสผ่านแทนตลอด

การขาย iPhone ที่ Face ID เสียยังเป็นไปได้ในหลายกรณี แต่กรอบราคาเบื้องต้นจะขึ้นกับ **รุ่น ความจุ สภาพจอ กล้อง TrueDepth** และว่ามีอาการร่วม เช่น จอแตก น้ำเข้า หรือเคยซ่อมจอคุณภาพต่ำหรือไม่

## สาเหตุที่ Face ID เสียที่พบบ่อย

- **กระแทกหรือหล่น** บริเวณด้านบนหน้าจอ (กล้อง TrueDepth เสียหาย)
- **น้ำเข้า** หรือความชื้นสะสมในรอยบัว
- **ซ่อมจอ** โดยไม่ถอด/ติดตั้งเซนเซอร์ TrueDepth อย่างถูกต้อง
- **จอเสียเป็นชุด** ที่กระทบแพรหรือสายแพรจอ
- **อัปเดตระบบค้าง** หรือรีเซ็ตแล้วยังไม่กลับมา (พบน้อยกว่า — ควรลองรีสตาร์ทก่อน)

แจ้งสาเหตุที่ทราบตรง ๆ ช่วยให้ทีมงานประเมินได้ใกล้เคียงขึ้น

## เราประเมินอย่างไร

เราไม่กำหนดราคาตายตัวบนหน้าเว็บ แต่จะดูข้อมูลจริงจากรูปและคลิปที่คุณส่ง

**ปัจจัยหลักที่ใช้ประเมิน**:

1. รุ่นและความจุ (เช่น iPhone 15 Pro Max vs iPhone 11)
2. สภาพจอ — แตก เป็นเส้น ทัชเสีย หรือปกติ
3. กล้อง TrueDepth — รอย ฝ้า หรือเสียหายชัด
4. ประวัติซ่อม — เปลี่ยนจอที่ไหน เมื่อไหร่
5. แบตเตอรี่และ Battery Health
6. กล้องหน้า-หลัง ลำโพง และฟังก์ชันอื่น ๆ
7. เครื่องศูนย์ไทยหรือเครื่องนอก
8. อุปกรณ์ที่มี (สายชาร์จ กล่อง)

หากเครื่องยังติดบัญชีผู้ใช้ ต้องจัดการเรื่อง **Apple ID / Find My** ก่อน — ดูที่ [ไอโฟนติด iCloud ขายได้ไหม](/รับซื้อไอโฟน/ติด-icloud/)

## สิ่งที่ควรเตรียมก่อนส่งประเมิน

1. **รูปหน้าจอ About** — แสดงรุ่นและความจุ (Settings → General → About)
2. **รูปรอยบัวด้านบน** — ถ่ายหลายมุมให้เห็นรอยชัด
3. **คลิปสั้น 5–10 วินาที** — ลองสแกน Face ID แล้วแสดงข้อความ error (ถ้ามี)
4. **รูปจอและขอบเครื่อง** — โดยเฉพาะถ้าจอแตกหรือมีรอย
5. **แจ้งประวัติ** — ตกน้ำ ซ่อมจอ หรือเปลี่ยนแบตหรือไม่
6. **แจ้งเครื่องศูนย์ไทย/นอก** และพื้นที่ที่อยู่
